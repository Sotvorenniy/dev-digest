# mcp (@devdigest/mcp)

Local stdio MCP server: a thin wrapper over the dev-digest REST API (:3001) that
exposes five tools to Claude Code.

## Before answering
Search `mcp/docs/`, `mcp/specs/`, `mcp/INSIGHTS.md` first.
Read `mcp/INSIGHTS.md` before working here and name the entries that apply. Treat them as high-confidence guidance.

## Conventions (not obvious from code)
- **Never write to stdout.** stdout is the MCP transport; one stray `console.log` corrupts the protocol. Log through `src/log.ts` (stderr only). `test/no-stdout.test.ts` greps `src/` for it.
- Thin wrapper: no DB, no `server/` imports, no cross-package imports (nothing aliased to `server/src/vendor/shared`). Response schemas are our own minimal copies in `src/api/schemas.ts` (strip mode, `.nullish()`, never `.strict()`); re-check them whenever a server contract changes.
- Config is `DEVDIGEST_API` only (default `http://localhost:3001`). No secrets; the server resolves the workspace, the MCP sends no auth.
- Tool rules: snake_case `verb_noun` names; `description` 150-300 chars (the verbatim strings live in `src/tools/descriptions.ts`; `get_blast_radius` is the one exception at 100-300); flat arguments, at most 5 (`get_findings` uses all five: `repo`, `pr`, `run_id`, `min_severity`, `cursor`; keep other tools at 4 or fewer); every param `.describe()` 40-80 chars; no `outputSchema`; output is one minified-JSON text block capped at 12K chars with paging; `instructions` 300-600 chars.
- Errors are `isError` results with short text that names the next step ("agent not found; call list_agents"). Handlers never throw and never forward response bodies or trace text.
- `run_agent_on_pr` blocks up to 120 s by polling `GET /pulls/:id/runs`, and **never cancels a run** (not on timeout, not on abort). On timeout it returns `run_ids` and tells the model to call `get_findings`.
- `get_blast_radius` is implemented (reads `GET /pulls/:id/blast`); its input shape is frozen.
- No `list_repos` / `list_prs` tools (`gh pr list` covers it). The MCP calls `GET /repos` and `GET /repos/:id/pulls` internally only, to resolve names to ids.
- npm, ESM, run with tsx. Do not use `pnpm`; use `./node_modules/.bin/<bin>` if needed.

## Do not touch
- `server/**` — if a route is missing, stop and re-plan; never edit the server from here.
- `mcp/package-lock.json` by hand — generated by npm; never unify with other lockfiles.
- The final tool description strings — changing one needs user approval.

## Use when
- Install, run, tool table, troubleshooting → read `mcp/README.md`
- Findings and gotchas → read `mcp/INSIGHTS.md`
- Measuring the `tools/list` token cost → `cd mcp && npm run measure`
